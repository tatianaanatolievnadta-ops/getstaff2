# Привязка домена к GitHub Pages (GETSTUFF)

Сайт сейчас: https://tatianaanatolievnadta-ops.github.io/getstaff2/  
Домен: **https://gstmetiz.shop/** (Reg.ru)

---

## Важно

DNS-серверы должны быть **ns1.reg.ru / ns2.reg.ru** (как у вас на скрине).  
Сейчас домен «припаркован» Reg.ru — после смены A/CNAME парковка уйдёт, откроется сайт GETSTUFF.

Почта на `гетстафф.рф` / Beget к этому домену не относится — не путать.

---

## Шаг 1. GitHub (сделать первым)

1. Откройте репозиторий: https://github.com/tatianaanatolievnadta-ops/getstaff2  
2. **Settings → Pages**  
3. **Custom domain** → введите: `gstmetiz.shop`  
4. **Save**  
5. Когда DNS подхватится — включите **Enforce HTTPS**

В корне репозитория файл `CNAME` = одна строка: `gstmetiz.shop`

---

## Шаг 2. DNS в Reg.ru для `gstmetiz.shop`

Сейчас: `@` и `www` → `95.163.244.138` (парковка Reg.ru). Заменить на GitHub.

### A) Корень `@`

1. Удалите A `@ → 95.163.244.138`  
2. **+ Добавить запись** — четыре раза тип **A**, хост `@`:

| Тип | Хост | Значение |
|-----|------|----------|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |

### B) `www`

1. Удалите A `www → 95.163.244.138`  
2. Добавьте **CNAME**:

| Тип | Хост | Значение |
|-----|------|----------|
| CNAME | `www` | `tatianaanatolievnadta-ops.github.io` |

Без `/getstaff2`, без `https://`.  
DNS-серверы оставьте `ns1.reg.ru` / `ns2.reg.ru`.

---

## Шаг 3. Проверка

Через 15 мин – несколько часов:

1. https://gstmetiz.shop/ — сайт GETSTUFF (не парковка Reg.ru)  
2. https://www.gstmetiz.shop/ — тоже  
3. В GitHub Pages — зелёная галочка + **Enforce HTTPS**

Старая ссылка github.io обычно продолжает работать.

---

## Если не открывается

| Симптом | Что проверить |
|--------|----------------|
| Сайт старый / чужой | Не те NS / старый IP 95.x ещё не сняли |
| ERR_SSL / сертификат | Подождите Enforce HTTPS (до 24 ч после верного DNS) |
| 404 GitHub | В Pages указан другой репозиторий / нет файла CNAME / ветка не `main` |
| Почта пропала | Верните MX-записи регистратора |
