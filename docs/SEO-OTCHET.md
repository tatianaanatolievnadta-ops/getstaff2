# Отчёт: SEO-оптимизация GETSTUFF

**Дата:** 03.10.2026  
**Сайт (канонический):** https://gstmetiz.shop/  
**Зеркало:** https://tatianaanatolievnadta-ops.github.io/getstaff2/

---

## Цель

Чтобы сайт попадался в поиске по «горячим» запросам (саморезы, кровля RAL, опт крепежа) и заявки с поиска конвертировались в заказы.

---

## Что сделали

### 1. Канонический домен
- Все `canonical`, `sitemap.xml`, `robots.txt`, `LEGAL.site` переведены на **https://gstmetiz.shop**
- Файл `CNAME` = `gstmetiz.shop` (для GitHub Pages)

### 2. Метатеги под коммерческие запросы
| Страница | Title / фокус |
|----------|----------------|
| Главная | саморезы и крепёж купить, −15% к WB, опт |
| Каталог | каталог саморезов, фильтры размер/покрытие |
| Опт | крепёж оптом, тарифы −15/−25/−35% |
| Статьи | гайды по выбору крепежа (уже были) |
| Товар | динамический title + Product schema |

Добавлены: `description`, `keywords` (где уместно), Open Graph, Twitter Card.

### 3. Разметка для поисковиков (JSON-LD)
- **Organization** + **WebSite** (+ SearchAction) на главной  
- **FAQPage** на странице опта (3 частых вопроса про пороги и скидки)  
- **Product** на карточке товара (через `js/seo.js`)

### 4. Техническое SEO
- `robots.txt`: Allow `/`, Sitemap на gstmetiz.shop, Disallow корзина/оформление/избранное  
- `noindex` на cart / checkout / favorites (чтобы не засорять выдачу)  
- Скрытый **H1** на главной (ключ «саморезы и строительный крепёж»)  
- 20 статей с обновлёнными canonical под домен + OG article  
- Cache-bust CSS `?v=20261003seo`

### 5. Контент под заказы (уже было + усилили мета)
Горячие темы статей (трафик → каталог/заявка):
- саморезы по дереву / 3,5 и 4,2  
- кровельные RAL, EPDM, металлочерепица  
- опт крепежа, сайт vs WB  
- покрытия цинк/фосфат, расчёт количества  

CTA в статьях ведут в каталог / checkout / опт.

---

## Что сделать вам (вне кода)

1. **Домен:** в Reg.ru A-записи на IP GitHub + CNAME www (см. `docs/DOMEN-GITHUB.md`). Пока домен «припаркован» — поисковик не увидит сайт.  
2. **GitHub Pages → Custom domain** `gstmetiz.shop` + Enforce HTTPS.  
3. **Яндекс.Вебмастер** + **Google Search Console** → добавить `gstmetiz.shop`, отправить sitemap:  
   `https://gstmetiz.shop/sitemap.xml`  
4. Раз в неделю — 1 пост/Reels со ссылкой на статью или категорию (ускоряет индексацию).  
5. Не ждать позиций завтра: по новым доменам обычно **2–8 недель** на стабильную выдачу.

## Ожидаемый эффект

| Срок | Что реально |
|------|-------------|
| 1–2 недели | индексация главной, каталога, части статей |
| 1–2 месяца | запросы «GETSTUFF», длинные статьи, низкочастотные «саморезы RAL …» |
| дальше | рост за счёт опта + контента + отзывов |

SEO даёт **трафик**; заказы закрывает менеджер по скрипту (`docs/SKRIPT-ZVONKA.md`) и цена −15%/опт.
